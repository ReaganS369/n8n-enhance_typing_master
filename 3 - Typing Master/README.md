# 🚀 TYPE//TANK — Modern Kinetic Defense

A browser-based kinetic typing defense game built using **HTML5 Canvas 2D, modern CSS glassmorphism, and vanilla JavaScript**, powered by native procedural **Web Audio API** sound synthesis (zero external audio or library dependencies).

---

## 🎯 5 Distinct Gameplay Modes

1. **🛡️ ENDLESS DEFENSE (Classic Survival)**:
   - Defend your hull (100 HP) against progressively accelerating waves of threats.
   - Hull damage on breach (20% normal, 30% crimson bonus).

2. **⏱️ 60s TIME BLITZ**:
   - Fast-paced 60-second score rush.
   - Infinite hull health: breaches deduct 150 points & break combo instead of ending the run.
   - Maximize words destroyed and peak WPM before the clock hits zero!

3. **👾 TITAN DREADNOUGHT (Boss Battle)**:
   - A massive alien mothership descends and hovers at top-center with a 1200 HP Boss health bar.
   - Eliminating descending drones and heavy EMP torpedoes ricochets devastating kinetic laser blasts directly into the Boss.
   - Defeat the boss to trigger a multi-stage celebratory explosion!

4. **💀 SUDDEN DEATH (Hardcore Perfectionist)**:
   - Hull Integrity: **1 HP**!
   - A single breach ends the mission immediately.
   - Massive **5.0× score multiplier** across all neutralized targets!

5. **💻 HACKER CODE MATRIX**:
   - Real developer syntax: `const`, `await`, `function()`, `fetch(api)`, `useState()`, `git.push()`.
   - Tactical power-ups spawn randomly:
     - ❄️ `[FREEZE]`: Chrono-stasis freezes all falling threats for 4.5 seconds.
     - 💣 `[NUKE]`: Orbital ion blast obliterates all visible threats on screen.
     - 🛡️ `[SHIELD+]`: Restores +25% hull integrity.

## 🕹️ Controls & Hotkeys

| Key | Action |
| :--- | :--- |
| **Typing Keys** | Target and fire railgun at descending threats |
| **Enter / Space** | Confirm / Advance screens / Redeploy sortie |
| **Esc** | Pause / Abort tactical sortie |
| **R** | Open Flight Logs from Sortie Debrief screen |
| **Header Buttons** | Switch Theme, Toggle Aspect Ratio, CRT Filter, Audio Mute, Callsign |
